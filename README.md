# Want It / Need It

Buyer-first listings. Craigslist inverted.

- **Want it** — vague desire. Price optional.
- **Need it** — real good or service. Hard max $ or flexible minimum $.
- Sellers compete on the buyer’s terms.
- Money never sits on this site. Buyer pays seller off-site.
- Like = interest. Want/Need it too = pile-on at that price band so a seller can cut unit price for quantity.
